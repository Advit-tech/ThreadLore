How to get your personal User Token in 10s (Zero Admin Rights)
  1. Open Discord in your browser (Chrome/Edge/Firefox) at discord.com/app.
  2. Press F12 (or Ctrl+Shift+I) and select the Network tab.
  3. Click into any channel or type a message in Discord.
  4. Click on any network request named messages or @me.
  5. Scroll to Request Headers and copy the authorization string.
  6. Paste it below. Leave "Bot Token" unchecked!
